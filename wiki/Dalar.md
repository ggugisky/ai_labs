# Dalar

> Source: [Dalar](https://www.dalar.ai/)
> Meeting: [[raw/meeting/20260807]]

## 한줄 요약

Dalar는 프롬프트를 직접 조립하기보다 대화와 레퍼런스를 바탕으로 브랜드용 이미지·영상 콘텐츠를 만드는 크리에이티브 AI 서비스로 소개됐다.

## 미팅에서 확인한 핵심

- 사진 한 장에서 사람, 상품, 공간의 특징을 유지하며 콘텐츠를 확장한다.
- 사용자가 복잡한 프롬프트를 직접 작성하기보다 대화형 입력으로 원하는 결과를 구체화한다.
- 동일한 인물·상품·공간 레퍼런스를 유지하면서 반복 콘텐츠를 제작한다.
- 사진, 텍스트, 이미지, 영상 요소를 하나의 브랜드 콘텐츠 흐름으로 묶는다.

## 제품의 성격

Dalar는 자율 에이전트라기보다 `브랜드 콘텐츠 생성 스튜디오`에 가깝다. 사용자의 의도를 대화로 수집하고, 일관된 레퍼런스를 유지하며, 제작 결과물을 빠르게 반복하는 UI·워크플로우가 핵심이다.

## 활용 흐름

1. 상품·인물·공간의 대표 이미지를 입력한다.
2. 대화로 콘텐츠 목적과 스타일을 설명한다.
3. 레퍼런스의 정체성을 유지한 이미지 또는 영상 시안을 만든다.
4. 시안을 반복 수정해 브랜드 채널에 쓸 콘텐츠로 확장한다.

## 장점

- 프롬프트 작성 부담을 줄여 비전문 사용자도 접근하기 쉽다.
- 상품·인물·공간의 일관성을 유지하는 콘텐츠 반복 제작에 적합하다.
- 생성 모델 자체보다 콘텐츠 제작 경험과 결과물 관리에 집중한다.
- 하네스를 실제 사용자용 서비스로 포장할 때 필요한 UI 흐름을 보여준다.

## 한계와 주의점

- 브랜드 정체성 유지가 실제 생성 모델과 입력 레퍼런스 품질에 좌우된다.
- 상업적 사용 시 학습 데이터, 인물 초상권, 상품 이미지 권리 확인이 필요하다.
- 대화형 UX가 편리해도 결과물 검수와 브랜드 가이드라인은 별도로 필요하다.
- 현재 공개 자료만으로 모델 구성·가격·API 범위를 확정하기는 어렵다.

## AI Labs 시사점

Dalar의 핵심은 하네스의 복잡성을 사용자에게 노출하지 않고 `의도 입력 → 레퍼런스 유지 → 반복 생성 → 결과 선택`으로 감추는 제품화 방식이다. AI Labs에서 개발 중인 서비스도 내부 에이전트 구조와 최종 사용자 경험을 분리할 필요가 있다.
