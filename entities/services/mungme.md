# 멍미

반려동물 보호자가 사료의 성분·안전성·건강 지표를 이해하고 구매를 판단하도록 돕는 데이터 기반 서비스다. 발표자료에서는 공공·제조사 데이터를 수집해 사전과 규칙으로 판정하고, 추천 콘텐츠와 가격 정보를 제공하는 사례로 소개됐다.
