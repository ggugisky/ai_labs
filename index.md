# AI Labs Index

## Overview

AI Labs is a biweekly AI topic sharing and discussion group.

## Core Files

- [[log]]
- [[wiki/README]]

## Main Areas

- `raw/meeting/`: shared meeting notes by date
- `raw/`: drafts and source notes
- `wiki/`: reviewed reusable knowledge
- `ontology/`: allowed document classes and relation vocabulary
- `entities/`: people, organizations, services, use cases, and tools
- `scripts/export_lpg.py`: rebuildable SQLite LPG projection

## Graph Model

The Markdown/YAML files are the source of truth. Stable IDs and typed
relations provide the ontology-aware document graph; the SQLite LPG is
generated locally from those files and is never committed.
