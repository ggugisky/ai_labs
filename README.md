# AI Labs

This repository stores AI Labs meeting notes in a brain-template style LLM Wiki structure.

## Structure

- `AGENTS.md`: repository rules
- `index.md`: navigation
- `log.md`: history of changes
- `raw/meeting/`: shared meeting notes by date
- `raw/`: drafts and source notes
- `wiki/`: reviewed reusable knowledge
- `entities/`: canonical people, organizations, services, tools, and use cases
- `ontology/`: allowed classes, statuses, and relation vocabulary
- `promotions.yaml`: raw-to-entity/wiki promotion manifest
- `scripts/lint.py`: metadata and graph contract validation
- `scripts/promote.py`: promotion coverage validation
- `scripts/build_index.py`: generated navigation indexes
- `scripts/export_lpg.py`: disposable SQLite graph projection
- `obsidian-plugin/ai-labs-relations/`: Obsidian Reading view renderer for YAML relations
